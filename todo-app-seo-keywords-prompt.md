# Todo App SEO Keywords Prompt

Copy the prompt below and paste it into Claude or another AI assistant. Replace the bracketed fields with details about your app first. The final result should be saved as **Keywords.pdf**.

---

## PROMPT

You are an experienced SEO strategist. I have a todo app website and I need a keyword research report to help it rank in search engines and attract the right users.

### About my app
- **App name:** [Your app name]
- **What it does:** A todo / task management web app where users add, edit, complete, and filter tasks.
- **Key features:** [e.g. dark mode, drag-and-drop, due dates, priority levels, free to use, no sign-up needed]
- **Target audience:** [e.g. students, freelancers, remote workers, families]
- **Target country / language:** [e.g. India, English]
- **Business goal:** [e.g. free users, app downloads, premium subscriptions]

### What I need
1. **Primary keywords (5 to 8):** The main high-intent terms that describe the app directly, such as "online todo list" or "free task manager."
2. **Secondary keywords (15 to 20):** Related terms such as "daily planner app," "to do list for students," and "simple task tracker."
3. **Long-tail keywords (20 to 30):** Specific, lower-competition phrases that real users type, such as "todo app with due dates and reminders" or "best free to do list website no login."
4. **Question keywords (10 to 15):** Questions users ask, such as "how to organize daily tasks," which I can use for blog posts or FAQ sections.
5. **Competitor keywords (5 to 10):** Terms used by popular todo apps such as Todoist, Microsoft To Do, Google Tasks, and TickTick, along with ideas for how my app can differentiate itself.

### For each keyword, include
- Keyword phrase
- Search intent (informational, navigational, commercial, or transactional)
- Estimated search volume (low, medium, or high)
- Competition level (low, medium, or high)
- Suggested page or section to target (for example, homepage, features page, blog post, FAQ)

### Important notes
- If you do not have live search data, clearly say that the volume and competition values are estimates. I will verify them with a tool such as Google Keyword Planner, Ubersuggest, Ahrefs, or Semrush.
- Group the keywords by category so they are easy to read.
- Avoid keyword stuffing. Suggest natural phrases that fit a website's content.

### Final output format
Create a single PDF file named **Keywords.pdf** with these sections, in this order:
1. **Title page:** "Todo App SEO Keyword Research" and the date
2. **Summary:** Five to eight lines describing the best opportunities
3. **Primary keywords:** Table
4. **Secondary keywords:** Table
5. **Long-tail keywords:** Table
6. **Question keywords:** Bulleted list
7. **Competitor keywords and differentiation ideas:** Short paragraphs
8. **Suggested page-to-keyword map:** Table showing which page should target which keywords
9. **Next steps:** Five quick actions to improve SEO

Use clean tables with clear headings. Keep the layout simple and easy to read.
